# learning/

**Purpose**: A record of what's being learned along the way — technical concepts, AI engineering lessons, and startup lessons — separate from product documentation, since this is about the founder's growth, not the product's state.

**Will eventually contain**:
- Notes on technical concepts learned while building (explanations Claude gives that are worth keeping)
- Postmortems on mistakes and what changed as a result
- Notes on AI engineering practices that worked/didn't for this product

**Why it exists**: Per [CLAUDE.md](../.claude/CLAUDE.md) Teaching Philosophy, the user should understand the reasoning behind decisions well enough to challenge them. This folder is where that understanding gets captured so it compounds instead of being re-explained every session.
