# progress/

**Purpose**: A running, dated record of what's actually been built and shipped — the factual history of project state, distinct from `roadmap/` (future plans) and `.claude/PROGRESS.md` (Claude's own session-tracking doc).

**Will eventually contain**:
- Dated milestone logs (e.g., "2026-07-15: WhatsApp webhook integration live in staging")
- Weekly/monthly summaries of what changed
- Metrics snapshots once there are real users (conversations handled, bookings made, escalation rate)

**Why it exists**: Without a factual log, it's easy to lose track of what's actually done versus planned, especially as scope evolves through customer validation. This is the ground truth to check claims of progress against.
