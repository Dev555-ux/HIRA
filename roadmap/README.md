# roadmap/

> **HIRA v1.x Architecture Baseline** (architecture consolidation, 2026-07-12)
> This roadmap is now considered the HIRA v1.x architecture baseline.
> Changes to this roadmap should only occur when:
> - production usage demonstrates a limitation,
> - significant technical constraints appear,
> - or the business direction intentionally changes.
>
> Architecture should evolve from evidence, not preference.

**Purpose**: Where HIRA is headed — the sequencing of features, verticals, and milestones from MVP to the longer-term AI Business Operating System vision.

**Will eventually contain**:
- MVP scope definition and milestone tracking
- Vertical validation plan (dental, beauty, immigration consulting, gyms, real estate, cafés/restaurants) and criteria for picking the first production vertical
- Phase plan: Assisted Mode → Autonomous Mode → additional "AI employee" roles beyond receptionist
- Quarterly/monthly planning notes

**Why it exists**: The product scope is intentionally narrow right now (AI Receptionist only) but the vision is much larger. This folder keeps the sequencing explicit so scope stays disciplined — work maps to a stated phase rather than expanding ad hoc.
