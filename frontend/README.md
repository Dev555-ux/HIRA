# frontend/

**Purpose**: The dashboard/admin interface businesses (and internally, HIRA's team) use to configure the AI receptionist, review conversations, and manage appointments — not the customer-facing chat itself, which happens inside WhatsApp.

**Will eventually contain**:
- Business owner dashboard (knowledge base editor, calendar view, escalation inbox)
- Conversation history viewer
- Onboarding/setup flow (connect WhatsApp, connect Google Calendar, upload FAQs)
- Internal admin tools (multi-tenant management, monitoring)

**Why it exists**: Even though the end customer interacts via WhatsApp, the business owner needs a control surface to configure HIRA, review what it's doing, and step in on escalations. This is that surface.
