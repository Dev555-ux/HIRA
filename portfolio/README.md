# portfolio/

**Purpose**: Externally-presentable material about HIRA — content meant to be shown to investors, customers, partners, or used as the founder's own portfolio piece.

**Will eventually contain**:
- Pitch deck materials
- Demo videos/screenshots
- Case studies once there are pilot customers
- One-pagers / executive summaries

**Why it exists**: Internal documentation (in `documentation/`) and external-facing material have different audiences and different standards of polish — separating them avoids either compromising internal clarity for presentation polish, or leaving external material undermaintained.
